This folder contains code for the crmarker package, which
needs to be installed on the online test server aim.shef.ac.uk
(because it is imported by the marking code for the online tests)

If any changes are made, the package needs to be rebuilt and reinstalled as follows:
run 
      python -m pip install --upgrade build   
[if this has not been done already]

in the crmarker folder, run
      python -m build

In crmarker/dist there should now be a new file crmarker-0.0.1-py3-none-any.whl
Log in to aim.shef.ac.uk and upload the above file.  (If you are using MobaXTerm
to connect to aim.shef.ac.uk, then you can use the file manager panel on the
left to do the upload).  Then go to the folder where the file was uploaded and
run 
      sudo pip3 install --force-reinstall crmarker-0.0.1-py3-none-any.whl
